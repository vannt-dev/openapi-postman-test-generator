# Postman Collection v3 schema

`collection.schema.json` is a copy of the Postman Collection v3.0.0 JSON schema (draft-07) from
https://schema.postman.com/collection/json/v3.0.0/draft-07/collection.json, published by Postman
from https://github.com/postmanlabs/schemas under the Apache License 2.0. It is used only by the
tests to validate the `--format v3` output and is not part of the npm package.
